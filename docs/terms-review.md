## 1. CVDp-h はガイドラインのどこに当たるか

- ガイドラインの「デジタルゲームに関するガイドライン」は、**入力に応じて表示や挙動が変わるプログラム**を対象にしています。対象には「インタラクティブWebアプリ」も含まれます。CVDp-h（タップで色が変わる、ゲームがある）はここに含まれると読むのが自然です。
- **無償で配布するもの**は「全般ガイドライン」に従えばよく、個別の申請はいりません。
- **有償で配布する場合**は「holo Indie」の審査・承認が必須です。

## 2. 公開方法ごとの結論

| 公開方法 | ホロライブの規約 | そのほかのハードル | 判断 |
|---|---|---|---|
| GitHub Pages（Web・PWA） | 無償なら全般ガイドラインの範囲で可 | 特になし | ◎ 第一候補 |
| Android：APK を GitHub Releases で無償配布 | 同上 | 利用者が「提供元不明のアプリ」を許可する必要がある | ○ |
| Android：Google Play で無償配布 | ガイドラインに禁止の記載なし | Play の知的財産ポリシー上、他社IPの名前を使うアプリは審査や通報で削除されるリスクがある | △ |
| iOS：App Store | ガイドラインに禁止の記載なし | Apple の審査ガイドライン（5.2 知的財産）で、権利者の許可がない他社IPを使うアプリはリジェクトされやすい。開発者登録も年額有料 | ✕〜△ |
| iOS：PWA（ホーム画面に追加） | Web と同じ | ストア審査なし。オフラインでも動く | ◎ iPhone はこれを推奨 |
| 有料・広告・投げ銭 | holo Indie の承認が必要（有料の場合） | 収益化は「営利目的」と見なされやすい | ✕ 避ける |

※ Apple・Google のストアポリシーは今回原文を確認していません（一般的な知識に基づく注意点です）。ストア申請を考えるときは改めて確認します。

**おすすめの順番：** GitHub Pages（PWA）で公開 → 必要なら Android の APK を GitHub Releases で配布 → ストア配信は保留。

## 3. 守ること（全般ガイドラインから）

- **公式と誤認される表現をしない。** アプリ名・アイコンに公式ロゴや「hololive」の名前を使わない。全ページに「非公式の二次創作です」と表示する（実装済み）。
- **公式素材をそのまま使わない。** 公式イラスト・ロゴ・立ち絵をアプリに同梱しない。原典をそのまま使ったものは二次創作とは見なされません。
  - デバッグモードのメンバー画像は、データの `image` 列に**利用者が自分で使ってよい画像**を指定する方式にしています。リポジトリには入れません。
- **営利目的にしない。** 広告・有料機能・寄付ボタンは付けない。
- **タレントやコンテンツのイメージを損なわない。** 第三者の権利を侵害しない。
- **第三者の素材**（フォント・画像・コード）は、それぞれのライセンスを守る。いまのコードは外部ライブラリなしの自作です。

## 4. ペンライトまわり

- 「キングブレード」は株式会社ルイファン・ジャパンの商標です。アプリ名には使わず、説明で「〇〇対応」と書く程度にとどめます。ボタンの見た目は、一般的な半円の形だけを使い、製品デザインのコピーは避けています。
- 公式ペンライトの仕様（ネジ・長さ・カラー順など）は、公式の商品ページなど出典つきで `data/c_penlight_specs.csv` に記録します。

## 5. 協力者クレジット

- 色覚タイプは健康に関わる個人情報です。**本人の明確な同意**を取り、ニックネームでの掲載や空欄も選べるようにします。
- 募集文に「掲載する項目（名前・ファンネーム・色覚タイプ）」と「取り下げ方法」を書いておくと安心です。
